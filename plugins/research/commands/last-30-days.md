# last-30-days

Research any topic from the last 30 days across Reddit, X, and web.

## Usage

```
/last-30-days [topic]
/last-30-days [topic1], [topic2]
/last-30-days [topic] --quick
/last-30-days [topic] --deep
```

## Instructions

Invoke the `newsroom` skill with the user's arguments.

**Examples:**
- `/last-30-days photorealistic people in Nano Banana Pro` - prompting research
- `/last-30-days best Claude Code skills` - recommendations
- `/last-30-days what's happening with OpenAI` - news
- `/last-30-days web app mockups --deep` - deep research
- `/last-30-days Claude Code --reddit` - Reddit only
- `/last-30-days Claude Code --x` - X only
- `/last-30-days Claude Code --days 7` - last week only
- `/last-30-days Claude Code --refresh` - fresh results, bypass cache
- `/last-30-days Claude Code --reddit --days 7 --deep` - combine flags
