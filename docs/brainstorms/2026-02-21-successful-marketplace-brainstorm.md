# Successful Claude Code Plugin Marketplace

## What We're Building

A curated, verified Claude Code plugin marketplace that expresses the compound engineering philosophy as a practical, end-to-end system for humans and agents. The marketplace is a public repo with clear structure, documentation, and strict curation. It serves both external users and internal workflows (dogfooding), acting as the canonical place to document, maintain, teach, and implement Nathan's agentic AI workflows.

Versioning:

- **V1 (now):** Marketplace repo + curated plugins + documentation + listed in community marketplaces.
- **V2:** Growth and marketing research (Twitter profile strategy, engagement, article writing on Twitter).
- **V3:** Personal website/blog (nathanvale.com) with a defined tone and first post about the marketplace.

## Why This Approach

A curated, verified-only marketplace builds trust and credibility early. It avoids the overhead and ambiguity of open submissions while the system and standards are still forming. The external audience can adopt confidently, and internal usage keeps it grounded in real production needs. Sequencing V1 → V2 → V3 prevents marketing work from diluting the core product quality.

## Key Decisions

- **Curated/verified only for V1:** No unverified community tier initially; everything meets the bar.
- **Align to compound engineering loop:** Every plugin must map clearly to the four-step loop.
- **Strict documentation:** README + contribution guide + plugin standards + verification checklist + install guide are mandatory.
- **Marketplace conventions:** Follow established marketplace structures and naming conventions to reduce friction.
- **Category system:** Discovery, Execution, Verification, Compounding, plus Tooling as a shared cross-stage category.

## Non‑Negotiables

- Production quality only.
- Clear, consistent repo structure.
- Comprehensive docs for onboarding and usage.
- Explicit alignment to the four-step compound engineering loop.
